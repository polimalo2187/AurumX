# AurumX Backend

Backend inicial para AurumX Mining.

## Stack

- Node.js
- Express
- TypeScript
- MongoDB / Mongoose
- BSC / BEP20 preparado para integración posterior

## Scripts

```bash
npm install
npm run dev
npm run build
npm start
npm run seed:machines
```

## Health check

```txt
GET /api/health
```

## Primer seed incluido

El seed crea los planes oficiales:

- Pico Inicial
- Excavadora
- Perforadora
- Trituradora
- Planta Élite
- Dragalina
